Architecture

Built for your network, not a datacenter

Three machines, one tailnet, zero cloud dependencies. Everything runs where you put it.

Primary · .1

pc-black

Brain, dashboard, all business apps, ORB5 trading engine, 35B LLM, and the source-of-truth git repo. The heart of the system.

Compute · .2

pc-white

Independent reviewer model, creative lane, embeddings, and batch inference. Optional — the system runs without it.

Mirror · .3

dev-desktop

Operator's Windows laptop. Source mirror and emergency worker. Pulls from .1, never pushes.

Network

Tailscale

All machines join one tailnet. Identity is verified per-request — no passwords, no tokens to copy, no cloud relay.

Setup

How it works

From bare machines to a running agent in four steps.

1

Install Tailscale

Each machine joins your private tailnet. No ports opened, no firewall rules, no cloud account.

2

Point at the repo

Trio pulls from a bare git repo on your primary machine. The live checkout is read-only; agents work in a source workspace.

3

Load your models

Point Trio at your local LLM endpoints. The 35B brain, the 14B reviewer, the creative lane — all on your hardware.

4

Open the dashboard

One URL. Chat, tools, research, trading, business apps — scoped to your identity, enforced by the network.
